01 / PROJECT

Do código ao navegador.

O projeto demonstra como um serviço web pode ser empacotado, configurado e executado de forma reproduzível.

01 DESAFIO

Disponibilizar a aplicação sem instalar o Apache diretamente no sistema.

O servidor fica isolado dentro do container, evitando configurações manuais no computador e deixando o ambiente mais simples de reproduzir.

CONTAINERIZED
02 ORQUESTRAÇÃO

Um comando inicia todo o ambiente.

docker compose up -d

03 / CONFIGURATION

Infraestrutura declarada em YAML.

O Docker Compose descreve a imagem, a porta de acesso, o volume e o comportamento do container.

  • 01 Imagem oficial do Apache
  • 02 Nome fixo para o container
  • 03 Reinicialização automática
  • 04 Bind mount somente leitura
docker-compose.yml 
services:
  apache:
    image: httpd:2.4
    container_name: docker-apache-web
    restart: unless-stopped

    ports:
      - "8080:80"

    volumes:
  - ./:/usr/local/apache2/htdocs:ro
YAML UTF-8 LF
